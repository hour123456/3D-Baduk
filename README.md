# 수담(手談) — 3D 정통 바둑 · 오목 게임

> **웹 브라우저 바로 플레이**: https://hour123456.github.io/3D-Baduk/

Three.js 기반 고해상도 절차적 PBR 그래픽, 2.5D 강체 물리 시뮬레이션, Web Audio API 물리 모델링 음향 합성, 엄격한 바둑(한국식·중국식) · 오목(렌주룰·자유룰) 규칙, 5단계 Web Worker 인공지능, 모바일 수직뷰/확대경/착수 실수 방지, 그리고 실시간 온라인 멀티플레이를 지원하는 **3D 바둑 · 오목 게임(웹 · 모바일 · Windows Electron 데스크톱 앱)** 입니다.

## 주요 특징

- **엄격한 바둑 · 오목 규칙 엔진 (`src/rules/`)**
  - **정통 바둑**: 한국식 규칙(집 + 사석, 기본 덤 6.5집) · 중국식 규칙(생존돌 + 집 면적, 기본 덤 7.5집), 64비트 Zobrist 해싱 기반 단패/초패 금지, `19·13·9줄`, `2~9점` 접바둑, 합의 계가 및 **SGF 기보 저장/불러오기** 지원
  - **정통 오목 (`GomokuEngine`)**: `15×15` · `19×19`, **렌주룰**(흑 삼삼·사사·장목 금수 실시간 판정 및 금수 자리 `✕` 표기, 정확히 5목 시 금수 면제) 및 **자유룰** 완벽 지원, 5목 달성 시 황금빛 승리 라인 연출
- **착수 모션 선택 & 90° 진짜 수직뷰 & 모바일 최적화 (`src/scene/`, `src/settings/`)**
  - **착수 모션 옵션**: 실제 대국처럼 손가락 끝 근거리에서 테두리가 먼저 닿았다가 복부로 딱 눕는 **실사 손가락 착수(기본)** 와 기존의 **바둑통 포물선 모션**, **즉시 착수** 선택 가능
  - **진짜 90° 수직뷰 (`OrthographicCamera`)**: 원근 왜곡 없는 직교 수직뷰 전환 및 회전 잠금 옵션, 스마트폰 세로 화면 자동 맞춤 모바일 수직뷰 지원
  - **착수 실수 방지 & 2.6× 터치 확대경**: 모바일/선택형 **2단계 착수 확인 바**(`◀ ▲ ▼ ▶` 1칸 미세 조정 + 착수 확정), 두 번 탭 착수, 손가락 드래그 시 손가락 위 오프셋 원형 확대경 지원
- **확장된 강체 물리 & 음향 · 조명 테마 (`StonePhysicsWorld`, `src/audio/`)**
  - 서브스텝 2.5D 원형 강체 충돌·쿨롱 마찰 기반 인접 돌 미세 밀림 및 착수 접촉 AO/파문 효과
  - 대추나무 바둑통 N-바디 흔들림·충돌 **잘그락거리는 소리**, 2단 스냅 착수음, 조명 테마 3종(`전통 한옥` / `밝은 대국실` / `야간 호롱불`)
- **업그레이드된 5단계 인공지능 & AI 추천수 (`src/ai/`)**
  - **바둑 AI**: 정적 위상 캐시 + 환격(Snapback)·양단수(Double Atari)·장문(Net/Geta)·급소(Nakade) 전술, LGRF-1 및 동적 덤 기반 MCTS `Lv.1 ~ Lv.5`
  - **오목 AI (`GomokuAI`)**: 4축 패턴 평가, Zobrist TT 반복 심화 알파-베타, `Lv.4~5` VCF(연속 4수 필승) 수읽기 탑재
  - 대국 중 **AI 추천수 Top 3** 확인 및 복기 모드 **AI 승률 그래프** 제공
- **플레이어 닉네임 & 실시간 온라인 2인 멀티플레이 (`src/profile/`, `src/online/`)**
  - **바둑 · 오목 모두 지원**: 빠른 매칭(종목·판 크기·렌주/자유룰 매칭), 방 만들기(공개/비공개 코드방), 6자리 코드·`?room=` 초대 링크 입장, 실시간 채팅·무르기·재대국 지원

## 실행 방법

```bash
# 의존성 패키지 설치
npm install

# 웹 브라우저 개발 서버 실행 (http://localhost:5173)
npm run dev

# Electron 데스크톱 앱 개발 모드 실행
npm run electron:dev

# 단위 테스트 실행 (규칙 및 AI 검증)
npm run test

# 웹 프로덕션 빌드 (dist/ 생성)
npm run build

# Windows 독립 실행형 데스크톱 앱 패키징 (release/win-unpacked 생성)
npm run electron:pack
```

## GitHub Pages로 웹사이트 열기

이 저장소에는 `.github/workflows/deploy-pages.yml` 자동 배포 워크플로가 포함되어 있습니다.
1. GitHub 저장소 상단의 **Settings** → 좌측 **Pages** 메뉴로 이동합니다.
2. **Build and deployment** 항목의 **Source**를 **GitHub Actions**로 변경하면 자동으로 빌드되어 웹 브라우저에서 바로 플레이 가능한 사이트 주소가 생성됩니다.
